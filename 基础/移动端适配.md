## 长度单位
### rem方案
1rem等于HTML根元素的font-size，可以通过JS动态计算
兼容性好，但是依赖JS脚本执行，可能会有短暂的闪烁
```js
document.documentElement.style.fontSize = document.documentElement.clientWidth / 10 + 'px'。
```
### vw/vh方案
1vw等于视口宽度的1%，纯CSS实现，性能更好
使用PostCSS插件在编译阶段将代码中的px转换为vw
- viewportWidth：视口宽度，根据这个基准算百分比
- minPixelValue：最小转换数值
- selectorBlackList：类名黑名单
- exclude：排除目录

## 高清屏
DPR(Device Pixel Ratio)设备像素是关键指标，等于物理像素/逻辑像素

### 图片
- img使用`srcset`属性，浏览器会自动根据屏幕DPR选择图片
```html
<img src="logo_1x.png" srcset="logo_2x.png 2x, logo_3x.png 3x">
```
### 背景图
使用媒体查询 `min-device-pixel-ratio`或`min-resolution`
```css
.icon {
  background-image: url('icon@1x.png');
}
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
  .icon { background-image: url('icon@2x.png'); }
}
```

### 1px
在DPR为2的屏幕上，`border: 1px`的代码，系统实际渲染的是2个物理像素

解决方案：
- 伪元素+Transform
将伪元素放大再缩小，精确实现物理1px，完美支持圆角，适配性较好
但是占用一个伪元素，代码量稍多
```css
.hairline-border {
  position: relative;
}
.hairline-border::after {
  content: "";
  position: absolute;
  top: 0; left: 0;
  width: 200%; height: 200%; /* 针对 DPR=2 放大两倍 */
  border: 1px solid #e0e0e0;
  transform: scale(0.5);      /* 缩回到 0.5 倍 */
  transform-origin: 0 0;
  pointer-events: none;       /* 防止遮挡点击事件 */
}
```
- box-shadow
利用阴影的延伸，模拟出极细的边框
但线条会有虚化感，不够锐利
```css
box-shadow: inset 0 -1px 0 0 #ddd;
```
- SVG背景图
SVG会根据屏幕自动寻找最细渲染路径，逻辑清晰，线条锐利
但复杂边框代码量较大
```css
.border-svg {
  background-image: url("data:image/svg+xml;charset=utf-8,<svg xmlns='http://www.w3.org/2000/svg' width='100%' height='1px'><rect fill='%23dddddd' width='100%' height='1px'/></svg>");
  background-repeat: no-repeat;
  background-position: bottom;
  background-size: 100% 1px;
}
```
- CSS原生
使用thin，但渲染结果不可控，取决于具体设备
```css
.native-thin {
  border: thin solid #ccc; /* 浏览器渲染为设备最细线 */
}
```
- viewport
动态设置`initial-scale`，将整个页面整体缩放至DPR比例
但可能影响第三方组件，动态修改viewport也会触发浏览器的Reflow
```js
var dpr = window.devicePixelRatio || 1;
var scale = 1 / dpr;
var metaEl = document.querySelector('meta[name="viewport"]');

// 动态设置缩放比例
var content = 'width=device-width, initial-scale=' + scale + 
              ', minimum-scale=' + scale + 
              ', maximum-scale=' + scale + 
              ', user-scalable=no, viewport-fit=cover';
```

## viewport
基本属性
- width：控制视口的（最小）像素宽度，可以设置正整数，也可以设置特殊值device-width，表示设备屏幕的物理尺寸
- initial-scale：控制页面首次加载时显示的缩放倍数，可0.1~10
- mininum-scale：允许缩小的倍数
- maxinum-scale：允许放大的倍数
- user-scalable：是否允许页面的放大和缩小操作
- viewport-fix：定义网页的可视区域
  - auto：不影响初始布局视口，整个网页都是可视的。
  - contain：视口被缩放，以适配显示区域内可内接的最大矩形。
  - cover：视口被缩放以填充设备显示区域

## 特殊屏幕
### 刘海屏/灵动岛
1. 设置viewport
必须在`meta`里添加`viewport-fit=cover`，否则浏览器默认会留出白边
2. 处理边距
env用于允许开发者将其内容放置在视口的安全区域中
```css
.safe-layout {
  /* 基础内边距 */
  padding: 1rem;
  
  /* 叠加安全区域（iOS 11+） */
  padding-top: env(safe-area-inset-top);
  padding-bottom: env(safe-area-inset-bottom);
  padding-left: env(safe-area-inset-left);
  padding-right: env(safe-area-inset-right);
}
```
### 折叠屏
用媒体查询
```css
/* 检测双屏/折叠屏 */
@media (horizontal-viewport-segments: 2) {
  .layout {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: env(viewport-segment-gap, 0);
  }
}
```
