
## empty

`:empty`代表没有子元素的元素

```jsx
// css
div {
  height: 20px;
}
div:empty {
  background: red;
}

// html 
<div></div> <!-- 生效 -->
<div>content</div>
```

## first-child

`:first-child`表示一组兄弟元素的第一个元素

```jsx
// css
p:first-child {
  color: lime;
}

// html
<div>
  <p>This text is selected!</p>
  <p>This text isn't selected.</p>
</div>
<div>
  <h2>This text isn't selected: it's not a `p`.</h2>
  <p>This text isn't selected.</p>
</div>
```

## first-of-type

与 `:first-child`类似，表示一组兄弟元素中其类型的第一个元素，但不会管其在兄弟内的位置如何

```jsx
// css
p:first-of-type {
  color: red;
}

//html
<h2>Heading</h2>
<p>Paragraph 1</p> // red
<p>Paragraph 1</p>
```

## last-child

`:last-child`表示父元素的最后一个子元素

```jsx
// css
li:last-child {
  background-color: lime;
}
// html
<ul>
  <li>此元素背景色不是lime</li>
  <li>我的也不是lime。</li>
  <li>我的才是lime!</li>
</ul>
```

## last-of-type

`:last-of-type`表示在子元素列表中最后一个给定类型的元素，也会包括子元素的最后一个子元素以此类推

```jsx
// css
p em:last-of-type {
  color: lime;
}

// html
<p>
  <em>我没有颜色 :(</em><br>
  <strong>我没有颜色 :(</strong><br>
  <em>我有颜色 :D</em><br>
  <strong>我也没有颜色 :(</strong><br>
</p>

<p>
  <em>我没有颜色 :(</em><br>
  <span><em>我有颜色!</em></span><br>
  <strong>我没有颜色 :(</strong><br>
  <em>我有颜色 :D</em><br>
  <span>
    <em>我在子元素里，但没有颜色!</em><br>
    <span style="text-decoration:line-through;"> 我没有颜色 </span><br>
    <em>我却有颜色！</em><br>
  </span><br>
  <strong>我也没有颜色 :(</strong>
</p>
```

## not

`:not()`匹配不符合一组选择器的元素

它不能被嵌套，也不能用伪元素来当做参数

```jsx
/* 选择所有不是段落（p）的元素 */
:not(p) { 
  color: blue;
}
```

## nth-child

`:nth-child(an+b)`会找到当前元素的兄弟元素，根据位置先后顺序排序，然后根据表达式里匹配的元素集合来选择

```jsx
// css
span:nth-child(2n + 1) {
  color: red;
}

// html
<span>A red</span> 
<span>B</span>
<span>C red</span>
<span>D</span>
```

## nth-last-child

`:nth-last-child`从兄弟节点中从后往前匹配

```jsx
// css
span:nth-last-child(2n + 1) {
  color: red;
}

// html
<span>A</span> 
<span>B red</span>
<span>C</span>
<span>D red</span>
```

## nth-of-type

`:nth-of-type`针对具有一组兄弟节点的标签

```jsx
/* 在每组兄弟元素中选择第四个 <p> 元素 */
p:nth-of-type(4n) {
  color: lime;
}
```

## nth-last-of-type

`:nth-last-of-type`和 `:nth-of-type` 基本一样，只是从结尾处反序计数

```jsx
// css
span:nth-last-of-type(2) {
  background-color: lime;
}

// html
<div>
  <span>This is a span.</span>
  <span>This is another span.</span>
  <em>This is emphasized.</em>
  <span>Wow, this span gets limed!!!</span>
  <strike>This is struck through.</strike>
  <span>Here is one last span.</span>
</div>
```

## only-child

`:only-child`用来匹配没有任何兄弟元素的元素

```jsx
// css
main :only-child {
  color: red;
}

// html
<main>
  <div>
    <i>I am a lonely only child !!!</i>
  </div>

  <div>
    <i>I have siblings.</i><br>
    <b>So do I!</b><br>
    <span>I also have siblings, <span>but this is an only child !!!</span></span>
  </div>
</main>
```

## only-of-type

`:only-of-type`代表任意一个元素没有其他相同类型的兄弟元素

```jsx
// css
main :only-of-type {
  color: red;
}
// html
<main>
  <div>I am `div` #1.</div>
  <p>I am the only `p` among my siblings !!!</p>
  <div>I am `div` #2.</div>
  <div>I am `div` #3.
    <i>I am the only `i` child !!!</i>
    <em>I am `em` #1.</em>
    <em>I am `em` #2.</em>
  </div>
</main> 
```
