## manualChunks

> `{ [chunkAlias: string]: string[] } | ((id: string, {getModuleInfo, getModuleIds}) => string | void)`
> 

`vite`底层使用 `rollup` 的 `manualChunks`来进行拆包，这个配置可以自定义拆包行为

```jsx
// 对象形式
// 会将所有的lodash模块打入到单独的chunk中
// 即使是通过 import get from 'lodash/get' 的方式引入
manualChunks: {
  lodash: ['lodash']
}

// 方法形式
// 把所有node_modules里的模块打入到vendor的chunk中
manualChunks(id) {
  if (id.includes('node_modules')) {
    return 'vendor';
  }
}
```

## vite拆包策略

在 `v2.8` 的时候，默认会将 `chunk` 分割为 `index` 和 `vendor`，但是这不是对每一种用例目标都能提供的通用解决方案，所以在 `v2.9` 里 `manualChunks` 默认不会被修改

一个通过 `create-vite` 生成的 `react-ts` 项目，在默认情况下的打包情况：


如果想用之前的分包策略，可以从 `vite` 中导入 `splitVendorChunkPlugin`来使用

```jsx

module.exports = defineConfig({
  plugins: [splitVendorChunkPlugin()]
```

可以看到将产物打成了 `vendor` 和 `index` 两种

可以发现在如下的例子中，产物中没有出现 `vendor`

```jsx
// vite.config.ts
import { defineConfig, splitVendorChunkPlugin } from "vite";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react(), splitVendorChunkPlugin()],
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          react: ["react", "react-dom"],
        },
      },
    },
  },
});
```

如果想配合使用，可以引入 `vite` 导出的 `splitVendorChunk`

```jsx
// vite.config.ts
import { defineConfig, splitVendorChunk } from "vite";
import react from "@vitejs/plugin-react";

const getVendorChunk = splitVendorChunk();

export default defineConfig({
  plugins: [react()],
  build: {
    rollupOptions: {
      output: {
        manualChunks: (id, options) => {
          if (id.indexOf("react") !== -1) {
            return "react";
          }
          return getVendorChunk(id, options);
        },
      },
    },
  },
});

// terminal
```

`splitVendorChunkPlugin`插件本质就是修改 `manualChunks`的配置

如果用户配置的 `manualChunks` 是个方法，则其没有返回值才会使用通过 `createSplitVendorChunk` 生成的 `viteManualChunks`，如果是对象形式的话不会做处理，因为无法安全复制 `rollup` 的行为（见注释）

```jsx
return {
    name: 'vite:split-vendor-chunk',
    config(config) {
      let outputs = config?.build?.rollupOptions?.output
      if (outputs) {
        outputs = Array.isArray(outputs) ? outputs : [outputs]
        for (const output of outputs) {
          const viteManualChunks = createSplitVendorChunk(output, config)
          if (viteManualChunks) {
            if (output.manualChunks) {
              if (typeof output.manualChunks === 'function') {
                const userManualChunks = output.manualChunks
                output.manualChunks = (id: string, api: GetManualChunkApi) => {
                  return userManualChunks(id, api) ?? viteManualChunks(id, api)
                }
              }
              // else, leave the object form of manualChunks untouched, as
              // we can't safely replicate rollup handling.
            } else {
              output.manualChunks = viteManualChunks
            }
          }
        }
      } else {
        return {
          build: 
            rollupOptions: {
              output: {
                manualChunks: createSplitVendorChunk({}, config)
              }
            }
          }
        }
      }
    },
  }
```

`createSplitVendorChunk`中调用了 `splitVendorChunk` 方法

将 `node_modules` 中非 `css` 的静态导入模块给打包到 `vendor` 中
```js
const cssLangs = `\\.(css|less|sass|scss|styl|stylus|pcss|postcss)($|\\?)`
const cssLangRE = new RegExp(cssLangs)
const isCSSRequest = (request: string): boolean =>
  cssLangRE.test(request)

function splitVendorChunk(
  options: { cache?: SplitVendorChunkCache } = {}
): GetManualChunk {
  const cache = options.cache ?? new SplitVendorChunkCache()
  return (id, { getModuleInfo }) => {
    if (
      id.includes('node_modules') &&
      !isCSSRequest(id) &&
      staticImportedByEntry(id, getModuleInfo, cache.cache)
    ) {
      return 'vendor'
    }
  }
}
```
