## 流式打字机
### 服务端
响应header设置
```js
res.setHeader("Content-Type", "text/event-stream; charset=utf-8");
res.setHeader("Cache-Control", "no-cache, no-transform"); // 不缓存、不转换内容（保护流式协议、确保数据完整性）
res.setHeader("Connection", "keep-alive");
res.setHeader("X-Accel-Buffering", "no"); // 控制Nginx是否对相应数据进行内部缓存，防止为了性能攒数据后一次性发送
res.flushHeaders(); // 立即向客户端发送HTTP响应头；让浏览器意识到是个流，开始进入等待数据块的状态
```
### 客户端

创建Reader读取，用TextDecoder来解析
```js
const response = await fetch('/api/chat-stream');
const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  // 持续读取每一块数据
  const { done, value } = await reader.read();
  
  if (done) {
    console.log("数据传输完成");
    break;
  }

  // 将字节码解码为字符串并显示
  const chunk = decoder.decode(value, { stream: true });
  console.log("收到新片段:", chunk);
  // 这里可以更新 UI，实现打字机效果
}
```

**注意事项：**
- 使用`event.isComposing`判断用户是否正在使用输入法进行组合输入，用于防止提前触发业务逻辑
